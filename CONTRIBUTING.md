# Contributing to Creative-AI 🤝

Thank you for considering contributing! This project is intentionally beginner-friendly.

### How to Contribute

1. **Fork** this repo
2. **Clone** your fork
```bash
git clone https://github.com/<your-username>/Creative-AI.git
```
3. **Create a branch**
```bash
git checkout -b feat/your-feature-name
```
4. **Make your change** — keep it small and focused
5. **Commit** with clear message
```bash
git commit -m "feat: add prompt template component"
```
6. **Push & Open a PR** with a short description

### Good First Issues

Look for labels: `good first issue`, `documentation`, `ui`, `help wanted`

Ideas:
- Improve README / docs
- Add a prompt template
- Add a UI component (button, card, modal)
- Fix a typo / accessibility issue
- Add an example

### Code Style

- TypeScript + Next.js + Tailwind CSS
- Clean, readable, commented code
- No secrets / API keys in PRs — use `.env.example`
- Keep components small and reusable

### Code of Conduct

- Be kind, respectful, and helpful
- No harassment, spam, or self-promotion
- We are here to learn together

### Questions?

Open an Issue with title `[Question] Your question` — maintainer will reply within 2-3 days.

Thanks for building in the open with us! ✨
